# DECISIONS

## D001. 원본 로고의 크기와 위치

원본 소스의 해상도와 화면상 크기는 유지 의무가 없다.

부기명 공간 확보를 위해 원본 로고 전체를 축소하거나 이동할 수 있다. 단, 종횡비를 유지하고 로고 내부 형태/색상/구성을 변경하지 않는다.

## D002. 원본 로고 보호 방식

생성형 AI가 반환한 전체 이미지를 최종 로고로 사용하지 않는다.

원본의 비배경 영역에서 보호 레이어를 만들고 최종 합성 시 원본 기반 보호 레이어를 사용한다. AI 결과가 로고 본체를 미세하게 변경하더라도 최종 결과에 반영되지 않도록 한다.

## D003. OpenRouter 사용 범위

AI가 필요한 모든 외부 모델 호출은 OpenRouter만 사용한다.

정확한 픽셀 처리가 필요한 배경 마스크, 투명화, 리사이즈, 위치 조정, 레이어 합성, PNG 인코딩은 로컬에서 처리한다.

## D004. 출력 기본값

기본 출력 크기는 200 × 60 px로 한다.

## D005. UI 분리

메인 창은 실제 편집 작업만 노출한다.

API Key, 기본 모델, 커스텀 모델 관리는 SettingsWindow로 분리한다.

## D006. 1차 저장 형식

1차 버전 결과 저장 형식은 PNG로 한정한다.
