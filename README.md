# DK Logo Editor

OpenRouter를 이용해 기존 로고를 보호하면서 배경과 부기명을 편집하는 Windows용 로고 편집 프로그램입니다.

## 핵심 원칙

- 원본 로고의 형태·색상·디자인은 생성형 AI가 수정하지 않습니다.
- 부기명 공간 확보를 위해 원본 로고의 표시 크기와 위치는 조정할 수 있습니다.
- 배경 영역만 색상 변경 또는 투명화할 수 있습니다.
- 부기명은 OpenRouter 기반 이미지 분석/생성을 이용해 자연스러운 위치와 스타일로 추가합니다.
- AI가 필요한 작업은 OpenRouter만 사용합니다.
- 최종 합성, 마스크 적용, 리사이즈처럼 정확성이 필요한 픽셀 작업은 로컬에서 수행합니다.

## 1차 목표

- 원본 로고 이미지 업로드
- 배경색 지정 또는 투명화
- 부기명 입력 및 AI 기반 자연스러운 배치
- 출력 크기 지정 (기본 200 × 60)
- OpenRouter API Key 설정
- 기본 이미지 모델 선택
- 커스텀 모델 추가/삭제
- 결과 미리보기 및 PNG 저장

## 개발 환경

- .NET 8
- WPF
- Windows
